# Bookcast：英文畅销书主题播客生成系统

## 项目简介

Bookcast 是一个面向读书内容创作的播客生成系统。

用户输入感兴趣的主题，例如死亡、轮回或虚拟世界。系统从英文畅销书榜单中筛选相关书籍，检索书评、出版社介绍和作者访谈，生成中文或英文的读书解读文稿，并使用用户选择的音色合成语音播客。

## 核心功能

1. **书单获取**：获取英文畅销书榜单，支持 CSV 导入。
2. **主题选书**：根据用户输入的主题筛选书籍，并说明匹配依据。
3. **资料检索**：收集专业书评、读者评论、出版社资料和作者访谈。
4. **资料评估**：核验书目身份、来源质量和主题覆盖，列出证据及缺口。
5. **中英文文稿**：基于可追溯资料生成读书解读播客稿。
6. **特色语音合成**：使用标准音色，或在取得授权后使用用户特色音色。
7. **成果交付**：支持查看、修改和下载文稿及音频。

## 技术方案

### 前端与后端

- **React + TypeScript + Vite**：用户操作页面。
- **Python + FastAPI**：提供书单、检索、任务和成果相关接口。

### 书单与资料检索

- **Amazon 畅销榜 / CSV**：获取或导入英文书单。
- **Tavily API**：按书名、作者和主题搜索评论与背景资料。
- **网页清洗与去重**：提取正文，区分书评、商品介绍和无关内容。

### 模型与多 Agent

- **兼容 OpenAI 协议的 LLM API**：用于主题判断、资料评估、
  中英文文稿生成和审稿。
- **AutoGen**：计划用于组织选书、检索、资料审核、
  文稿生成和审稿等 Agent 协作。
- Agent 的工具权限、协作流程、重试次数和成本限制在开发时确定。

### 任务与存储

- **RQ + Redis**：计划用于处理检索、写稿和音频合成等异步任务。
- **SQLite + SQLAlchemy**：保存书目、任务和资料。
- **Alembic**：管理数据库结构迁移。
- **PostgreSQL / 对象存储**：可按后续部署和规模需要接入。

### 音频

- **云厂商 TTS**：合成中英文播客语音，具体服务商待定。
- **音色克隆**：在取得用户或音色权利人授权后接入。
- **FFmpeg**：用于音频拼接、格式转换和导出。

## 业务流程

```text
用户输入主题、语言、时长和音色要求
        ↓
获取英文畅销书单
        ↓
筛选符合主题的候选书籍
        ↓
检索并核验书评、访谈和出版资料
        ↓
判断资料是否足以支撑节目
        ↓
多 Agent 协作生成并审核中英文播客稿
        ↓
TTS 合成用户选择的语音
        ↓
提供文稿与音频下载
```

## 协作方式

1. 在 Issues 中创建任务，说明目标和验收条件。
2. 从 `main` 创建功能分支，完成后提交 Pull Request。
3. 在 Pull Request 中说明修改内容、测试结果和已知问题。
4. 新框架、外部服务商及重大架构变更先由团队讨论确认。
